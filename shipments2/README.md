# 📝 Proyecto Final - Blog y Gestión en Django

Aplicación web desarrollada con **Python y Django** como proyecto final para el curso de Coderhouse. 

El sistema incluye funcionalidades de autenticación de usuarios, administración mediante el panel de Django, arquitectura MVT (Modelo-Vista-Template), formularios interactivos y preparación para despliegue en la nube.

---

## 🚀 Requisitos Previos

Asegúrate de tener instalado en tu sistema:
* **Python 3.10+**
* **Git**
* Un entorno virtual de Python (`.venv`)
